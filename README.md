# OrderFlow

Event-driven order processing on **.NET 10 microservices**, delivered to **Azure Kubernetes Service** through a GitOps platform.

> 🚧 Work in progress. See the [design document](docs/DESIGN.md) and the [implementation plan](docs/PLAN.md).

**Application:** Clean Architecture · CQRS · MassTransit + RabbitMQ · Outbox & Saga · YARP gateway · EF Core + PostgreSQL · Redis HybridCache · .NET Aspire · Testcontainers

**Platform:** Docker · GitHub Actions · Terraform · AKS · Helm · ArgoCD · Argo Rollouts · External Secrets + Key Vault · Prometheus · Grafana · Loki · Tempo · OpenTelemetry · k6 · Trivy · cosign
